## Locally executable evidence

The proof package under [`python/callysto_m0`](../../python/callysto_m0) uses only the Python
standard library. It is deliberately not the production converter or orchestrator.

It exercises:

- the exact `callysto-cell-id-v1` byte contract against shared Python/Node vectors;
- preservation of valid supplied IDs and fail-closed invalid, duplicate, or colliding IDs;
- a default-deny notebook-to-manifest converter that never executes notebook source;
- hostile active-output fixtures, MIME/signature checks, size limits, and canonical output;
- lease-epoch and draft-generation fencing semantics in a deterministic SQLite reference model.

Run:

```bash
npm run test:python
```

## Evidence boundary

This proof does **not** establish PostgreSQL concurrency, database-clock leases, Railway worker
isolation, secret absence, network egress denial, R2 integrity, Cloudflare delivery behavior, or
cross-origin browser isolation. SQLite is a state-transition model, not deployment evidence.

T004 remains open until the PostgreSQL and deployed worker tests in [`docs/TEST_PLAN.md`](../TEST_PLAN.md)
pass against the selected infrastructure. If Railway cannot enforce the required secret and egress
boundaries, the provider choice returns to owner review.
